Инструменты различают по методу запуска:
- Серверные инструменты (запускаются на инфраструктуре провайдера);
- Клиентские инструменты (запускаются в самом приложении, разработчик долен сам обработать запрос модели).

## Клиентские инструменты

После запроса модели с причиной остановки `tool_use` приложение с использованием входных данных из запроса запускает инструмент, а затем от роли ассистента результаты инструмента вместе с предыдущими сообщениями отправляются обратно модели.

## Агентский цикл

Цикл идет, пока `stop_reason` равен `tool_use`
1. Отправка запроса с вашим массивом `tools` и сообщением пользователя;
2. LLM отвечает с `stop_reason: "tool_use"` с одним или несколькими блоками `tool_use`;
3. Необходимо выполнить каждый инструмент. Вывод оформить в виде блоков `tool_result`;
4. Отправка нового запроса, содержащего исходные сообщения, ответ ассистента и сообщение пользователя с блоками `tool_result`;
5. Повторение шага 2, пока `stop_reason` равен `tool_use`.

## Применение инструментов

Стоит применять, когда:
- Действия с побочным эффектом(отправка email, запись файла);
- Свежие или внешние данные;
- Структурированные данные гарантированной формы;
- Обращение к существующим системам.

Не стоит применять, когда:
- Модель может ответить только на основе обучения;
- Задача без побочных ответов;
- Тривиальная задача(задержка будет доминировать над временем ответа).
