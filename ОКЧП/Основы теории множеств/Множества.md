**Определение:** *Множество* - объединение объектов, хорошо различимых нашей интуицией и мыслью (И. Кант).

**Определение:** *Множество* - это совокупность некоторых (произвольных) объектов, объединенных  по какому-либо признаку. Элементы множества при этом должны быть различными.

**Определение:** Будем считать, что мы выбрали и зафиксировали достаточно широкое множество, за пределы которого не будем выходить. Элементы всех множеств. которые будем рассматривать, будут одновременно являться элементами этого широкого фиксированного множества, называемого *универсальным*: $U$.

Множество образуется из элементов, обладающих некоторыми свойствами и находящимися между собой в некоторых отношениях.

**Способы задания множеств:**
1. Список;
2. Элемент определяется условиями по выбору из элементов другого множества;
3. Элемент определяется условиями по соответствию: $0 - 2^{0},1-2^{1}$;
4. Всякий элемент по предыдущему: $1,1,2,3,5,8,\dots$;
5. Как результат выполнения операций над множествами.

$x\in A$, $A$ - множество, $x$ - элемент множества, $\in$ - принадлежность

| $\varnothing$ - пустое множество - множество, не содержащее ни одного элемента.

| **Подмножество** $A\subset B$, если $\forall x  \ (x\in A\implies x\in B)$

|**Равенство множеств** $A=B$: Если $A$ и $B$ содержат одни и те же элементы.

|**Следствие**: из определения равенства множеств следует, что равенство не зависит от кратности и порядка элементов: $\{ a,b,c \}=\{ a,a,a,c,c,b \}$

Обозначение: конечное множество - $\{ a, b, c \}$
#### Свойства множеств
1. **Рефлексивность**: $A\subset A$
2. **Транзитивность**: $A\subset B,B\subset C\implies A\subset C$
3. **Антисимметричность**: $A\subset B,B\subset A\implies A=B$

#### Отличие $\subset$ и $\in$
Пример: $A=\{ a,\{ b \},c,\{ c \} \}$
Тогда $\{ a \}\subset A \ \ \ \ \{ a \}\not\in A$
	$\{ b \}\not\subset A \ \ \ \{ b \}\in A \ \ \ \{ \{ b \} \}\subset A$
	$\{ c \}\subset A \ \ \ \{ c \}\in A$
